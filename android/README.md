# YM Companion для Android

Приложение-компаньон к официальной Яндекс Музыке. Когда Яндекс включает цензурный трек, для которого у тебя есть файл, компаньон ставит Яндекс на паузу и играет твою explicit-версию. Когда она доиграет, Яндекс переключится на следующий трек. Само приложение Яндекс Музыки не меняется: компаньон пользуется стандартными командами плеера, как часы, скробблеры и автомобильные экраны.

> **Статус: прототип (0.1.0).** Работает подмена трека. Вставки в «Мою волну», автоимпорт и поиск оригинала появятся в следующих версиях.

## Установка

1. Открой на телефоне страницу [Releases → «YM Companion — тестовая сборка»](../../releases/tag/companion-dev) и скачай APK с самым большим номером.
2. Открой файл. Android попросит разрешить установку из этого источника (браузера или «Моих файлов») — разреши.
3. Новые сборки ставь поверх старой, удалять ничего не нужно.

## Настройка (один раз)

В приложении три шага:

1. **Доступ к уведомлениям.** Включи YM Companion в списке. Если переключатель серый с пометкой «Ограниченная настройка» (так Android 13+ защищает приложения, установленные из APK): Настройки → Приложения → YM Companion → ⋮ в правом верхнем углу → **«Разрешить ограниченные настройки»**, потом снова шаг 1.
2. **Папка с музыкой.** Выбери папку, где лежат твои explicit-версии (например, «Music» или «Download»). Подпапки тоже сканируются, до трёх уровней. Исполнитель и название берутся из тегов файла, иначе из имени (`Исполнитель - Название.mp3`).
3. **Работа в фоне.** Разреши. На Samsung дополнительно: Настройки → Приложения → YM Companion → Батарея → **«Без ограничений»**. Иначе One UI может усыпить компаньон.

Потом включи любой трек в Яндекс Музыке, для которого есть файл.

## Что видно

- В уведомлении и на экране блокировки — своя версия с кнопками «Пауза», «Дальше», «Закрыть». Кнопки наушников и Android Auto тоже управляют ею.
- В приложении — журнал: что играет в Яндексе, нашёлся ли файл и на какой миллисекунде трека Яндекс встал на паузу.

## Ограничения

- Внутри приложения Яндекса видно цензурный трек на паузе: их интерфейс компаньон не меняет.
- Первые доли секунды цензурной версии Яндекс успевает сыграть, пока Android сообщает о смене трека. Точное время показывает журнал.

## Сборка

APK собирает GitHub Actions при каждом изменении в `android/` (`.github/workflows/android.yml`): сначала юнит-тесты сопоставления (`MatcherTest`), потом `assembleDebug`. Локально: `cd android && gradle testDebugUnitTest assembleDebug` (Gradle 8.7, JDK 17, Android SDK 34).

Сборки подписаны одним и тем же отладочным ключом `app/debug.keystore`, поэтому новая версия ставится поверх старой. Это ключ прототипа, не для магазинов.
